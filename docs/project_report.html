Project Overview

This project delivers a complete, production-quality Autonomous AI Sales Voice Agent built for FORTIVEX AI Private Limited's advanced technical evaluation. It is not a mockup or static prototype — every component is functional, integrated, and runnable locally.

🎯

Mission

Automate the first stage of the sales funnel through natural voice/text AI interaction, lead qualification, and appointment booking.

🏗️

Architecture

Modular microservice-style design. FastAPI backend, React frontend, Gemini AI, ChromaDB RAG, local voice processing.

🔒

Privacy-First

Speech-to-text (whisper.cpp) and text-to-speech (Piper TTS) run entirely locally. No audio sent to external servers.

💰

Cost Model

Only the Gemini API (free tier) calls external services. All other AI components run on-device on Apple Silicon MPS.

System Architecture

📐 Architecture diagram: docs/architecture.png — open file directly to view.
Figure 1 — FORTIVEX Full System Architecture (see docs/architecture.png)

Data Flow

Customer voice input → whisper.cpp transcription → FastAPI routing → RAG Engine context retrieval from ChromaDB → augmented prompt to Gemini 1.5 Flash → AI response with optional tool calls (create_lead, book_appointment, etc.) → database writes → response text → Piper TTS synthesis → audio returned to browser.

Service Separation

GeminiService

Conversation engine, tool calling, sentiment analysis, lead extraction, call summarization. Session history cached in-memory per session ID.

RAGService

Document ingestion (PDF/TXT), chunking, sentence-transformer embedding on MPS, ChromaDB storage, semantic retrieval.

VoiceService

whisper.cpp subprocess for STT transcription. Piper TTS subprocess for speech synthesis. Health checks for binary readiness.

AgentService

Orchestrates all services. Routes messages, processes tool call results, persists conversation messages, computes sentiment & lead score.

Feature Implementation

💬

Conversational AI

Multi-turn context-aware chat using Gemini 1.5 Flash. Maintains per-session history. Graceful demo fallback without API key.

🎙️

Voice Input

Browser MediaRecorder API captures audio. Upload to backend → whisper.cpp transcription → chat pipeline. Metal/MPS accelerated.

🔊

Voice Output

Piper TTS synthesizes AI responses to WAV audio. Streamed back as audio/wav. Browser AudioContext plays response.

📚

Knowledge RAG

Upload PDF/TXT documents. Auto-chunked and embedded. Semantic search injects context into every Gemini prompt.

🏷️

Lead Qualification

AI tool calling auto-creates leads. Scoring 0–100 (HOT/WARM/COLD) based on intent, budget, timeline, and sentiment.

📅

Appointment Booking

AI books product demos via tool calling. Slot availability checks, confirmation messages, calendar data in SQLite.

❤️

Sentiment Analysis

Per-message sentiment (POSITIVE/NEUTRAL/NEGATIVE), buying intent, urgency, objections — JSON structured output from Gemini.

📊

Analytics Dashboard

Real-time stats: total leads, conversations, appointments, conversion rate, sentiment breakdown, lead score chart.

📝

Call Summarization

AI-generated structured summaries: requirements, products discussed, objections, recommended next action, lead score.

AI & NLP Pipeline

Gemini Tool Calling

The agent is equipped with 6 function tools that it calls autonomously based on context:

ToolTrigger ConditionEffect
create_leadCustomer name + 1+ qualifier collectedSaves lead to SQLite CRM
book_appointmentCustomer confirms demo requestCreates appointment row
get_available_slotsCustomer asks "when are you free?"Returns next 5 open slots
search_knowledge_baseProduct/pricing/feature questionSemantic RAG retrieval
generate_call_summaryGoodbye / "wrap up"AI-structured summary saved
update_leadNew info about existing customerUpdates lead fields in DB

Structured JSON Outputs

Lead analysis and sentiment analysis use Gemini's response_mime_type="application/json" to guarantee parseable structured output — no fragile regex parsing.

Demo Mode

When GEMINI_API_KEY is absent, a placeholder, or DEMO_MODE=true, all AI calls return pre-scripted realistic demo responses. The system is fully usable for evaluation without an API key.

Voice Processing

🎤

whisper.cpp — STT

Built from source with Apple Metal acceleration. Uses ggml-base.en.bin model for fast English transcription. Invoked via subprocess with WAV input.

bash scripts/setup_whisper.sh

🔊

Piper TTS — TTS

Offline neural TTS using en_US-lessac-medium ONNX model. Natural-sounding voice output. Runs entirely on-device, no network needed.

bash scripts/setup_piper.sh

⚠️ whisper.cpp and Piper require one-time manual setup (compilation / binary download). The backend gracefully handles their absence and reports "voice_ready": false in /health until configured.

RAG Knowledge System

The Retrieval-Augmented Generation (RAG) pipeline enables the agent to answer product and company questions accurately from documents, not from hallucinated training data.

Pipeline

  1. Upload PDF or TXT document via POST /api/knowledge/upload
  2. RAGService chunks text into ~500-token segments with 50-token overlap
  3. Sentence Transformers (all-MiniLM-L6-v2) generates 384-dim embeddings on Apple MPS
  4. Embeddings + metadata stored in ChromaDB (persistent local vector store)
  5. At chat time: query embedded → cosine similarity search → top-3 chunks retrieved
  6. Context injected into Gemini prompt as "KNOWLEDGE BASE CONTEXT"

Pre-loaded Documents

  • product_catalogue.txt — NovaTech product lineup, pricing tiers, features (11 chunks)
  • sales_faq.txt — Common customer questions, policies, support, ROI claims (14 chunks)

Setup & Running

Quick Start (1 command)

cd /path/to/fortivex-ai-sales-agent
bash start.sh

Manual Setup

# 1. Backend
cd backend
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt

# 2. Configure API key
cp .env.example .env
# Edit .env → set GEMINI_API_KEY=your_actual_key

# 3. Seed sample data
cd ..
bash scripts/seed_data.sh

# 4. Start backend
cd backend
uvicorn app.main:app --reload --port 8000

# 5. Frontend (new terminal)
cd ../frontend
npm install
npm run dev
# → http://localhost:5173
